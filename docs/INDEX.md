# XPEdit documentation

## Using the editor

Start with the [project README](../README.md) for installation, launch commands,
sprite browsing, animation previews and document export.

The [UI control reference](COMPLETE_UI_CONTROL_REFERENCE.md) describes the
editor controls. The [REXPaint manual](REXPAINT_MANUAL.txt) provides background
on the artwork format and editing conventions.

## File formats and development

The [PNG structural baseline](PNG_STRUCTURAL_BASELINE_CONTRACT.md) documents
image conversion behavior. The [XP editor contract](XP_EDITOR_ACCEPTANCE_CONTRACT.md)
describes document and editing behavior.

Run the Python and browser tests using the commands in the project README.
